For the grown-up: how this test works

The session mixes eight calls per name with similar-sounding words and sentences that mention a name. Recognition happens later; the page will not score the speaker or talk back. Keep the microphone, position and speaking volume the same throughout.

Audio stays in this page’s memory until you download it. Nothing is uploaded to a server or cloud service. Closing or reloading loses recordings that have not been downloaded. Each speaker needs a separate session. This short comparison does not qualify a complete wake system.
